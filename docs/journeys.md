# User Journeys

Ordered by value added to the co-op editors and community.

| Journey | Description | Effort | Completion |
|---|---|---|---|
| Compose & edit pages | Build structured site pages using accessible hero, text, gallery, callout, and FAQ sections. | 5d | 0% |
| Publish to headless API | Review staged drafts, publish snapshots to the delivery API, and trigger site webhooks. | 3d | 0% |
| Review membership applications | Triage prospective member applications and inquiries, log committee notes, and update status. | 3d | 0% |
| Schedule events & workshops | Publish public or member-only co-op events with accessibility notes and RSVP limits. | 3d | 0% |
| Publish news & announcements | Write, categorize, schedule, and publish co-op news and AGM notices. | 2d | 0% |
| Curate accessible media library | Upload photos and PDF guides with mandatory screen-reader alt text. | 3d | 0% |
| Manage navigation menus | Add, edit, and reorder header navigation and footer PDF resource links. | 2d | 0% |
| Maintain member directory | Add and update resident profiles, unit numbers, and committee roles for the portal. | 2d | 0% |
| Monitor studio overview | Track site metrics, recent editor activity, pending applications, and API health. | 2d | 0% |
| Sign in & recover access | Authenticate editors, persist 30-day sessions, and reset forgotten passwords via e-mail. | 2d | 0% |
| Invite co-op board editors | Invite board members by e-mail to join Esplanade and set their passwords. | 1.5d | 0% |
| Configure site & API keys | Manage site identity, scoped read-only delivery API tokens, and studio theme. | 1.5d | 0% |
